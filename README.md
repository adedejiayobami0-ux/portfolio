# Ayobami Portfolio — Experience-led Redesign

A ground-up portfolio concept built as a lightweight static site for GitHub Pages.

## What is included
- Editorial, designer-led visual direction rather than a generic SaaS/AI template
- Animated hero title sequence
- Contextual custom cursor
- Jovita AI flagship case study with scroll-driven product evolution story
- Interactive product UI mockup
- AWS workflow case study framing with confidentiality language
- Claude UX concept section
- Product philosophy, about, experience, and contact sections
- Responsive mobile design
- Reduced-motion accessibility support
- No framework or build step required

## Files
- `index.html`
- `styles.css`
- `script.js`

## Before publishing
1. Replace `hello@example.com` with your real public portfolio email.
2. Replace the placeholder LinkedIn `href="#"` with your profile URL.
3. Replace reconstructed UI with real Jovita screenshots when ready.
4. Verify every metric and job title before adding it.
5. If your current GitHub Pages repository serves from a `/portfolio/` path, these relative asset links will continue to work.

## Local preview
Open `index.html` directly, or run a tiny local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publishing to GitHub Pages
Copy these files into the repository currently powering your portfolio, commit, and push. If Pages is configured on the default branch/root, the redesign will replace the existing site.
